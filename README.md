# Global-Seminar-From-SKKU

이 GitHub Repository는 성균관대학교 Google Developer Group on Campus에서 운영하는 글로벌 IT전문가와 킹고인의 만남 세미나를 위한 간단한 리다이렉션 서비스입니다.

주요 역할은 행사 페이지와 피드백 페이지로 연결되는 짧고 편리한 링크를 제공하는 것입니다. 행사 현장에서 QR 코드나 링크를 쉽게 공유할 수 있도록 도와주며, 행사 웹 페이지 주소가 변경되거나 새로 구성될 때 해당 링크를 최신 상태로 유지하는 역할을 합니다.

## 구성 내용

- `index.html`
  - 링크: https://gdg-skku.github.io/global-seminar-from-skku/
  - 이 페이지는 동시 진행되는 글로벌 IT전문가와 킹고인의 만남 행사 메인 페이지로 리다이렉트됩니다.
  - 행사 참가자들이 QR 코드를 스캔하거나 링크를 눌러 행사 정보를 빠르게 확인할 수 있도록 합니다.

- `index.qr-code.png`
  - 이 QR 코드는 `https://gdg-skku.github.io/global-seminar-from-skku/` 주소를 나타냅니다.
  - 행사장에서 메인 페이지로 바로 이동할 수 있도록 배포용 QR 코드로 활용됩니다.

- `feedback.html`
  - 링크: https://gdg-skku.github.io/global-seminar-from-skku/feedback.html
  - 이 페이지는 동시 진행되는 글로벌 IT전문가와 킹고인의 만남 행사에 대한 피드백 폼 URL로 리다이렉트됩니다.
  - 참여자들이 행사 후 의견을 쉽게 제출할 수 있도록 연결됩니다.

- `feedback.qr-code.png`
  - 이 QR 코드는 `https://gdg-skku.github.io/global-seminar-from-skku/feedback.html` 주소를 나타냅니다.
  - 행사장 또는 발표 후 피드백 제출용으로 사용됩니다.

## Repository의 목적

이 저장소는 이벤트 홍보와 참여 유도를 위해 사용되는 "공용 링크 리다이렉션 서비스" 역할을 수행합니다. 특히 행사장에서는 긴 URL보다 짧고 직관적인 GitHub Pages 링크와 QR 코드가 훨씬 편리하며, 행사 운영에 필요한 여러 페이지를 안정적으로 연결해 줍니다.

## 유지 및 업데이트

행사 웹 페이지의 주소나 구조가 변경될 때마다, 2026 Fall부터는 Workspace Team 또는 글로벌 IT전문가와 킹고인의 만남을 Hosting하는 다른 GDG-SKKU 팀이 이 Repository의 소스 코드를 업데이트해야 합니다.

즉, 이 저장소는 단순한 정적 페이지가 아니라 행사 운영을 위해 필요한 리다이렉트 경로와 QR 코드 정보를 관리하는 공식적인 링크 유지 관리 저장소로 사용됩니다.

## 요약

이 Repository는 글로벌 IT전문가와 킹고인의 만남 행사에서 사용되는 메인 페이지 및 피드백 페이지를 간편하게 연결하는 서비스이며, GitHub Pages 기반의 URL 리다이렉트와 QR 코드 제공을 통해 행사 운영의 편의성을 높이는 역할을 합니다.
